Sources, rights and corrections

Magpie helps you find game assets on their original sites. It indexes metadata and links out; it does not host asset downloads. Magpie is independent and is not endorsed by the listed sources.

What a licence filter means

The catalogue records a licence option reported by the source. It may not include every available option, every contributor, or an asset's complete attribution instructions. Check the original page and the licence included with your download. A source's permission to use an asset does not automatically cover its website, preview images, trademarks, or other depicted rights.

The commercial filter is a conservative category filter, not a project-specific legal clearance. A licence such as CC BY-SA can allow commercial use while also imposing ShareAlike obligations. GPL is excluded from that conservative filter because compatibility needs individual review, not because GPL prohibits commercial use.

Source policy record

Official policies reviewed September 5, 2026. Policies can change; these notes are not a legal opinion.

  • Poly Haven. Collection uses its public API, with an identifying Magpie User-Agent. API-provided asset thumbnails are used for the asset-browser integration; website example renders and user renders are not collected. Powered by Poly Haven. The API attribution condition is distinct from the CC0 asset licence. API information · API terms · Asset and website terms.
  • ambientCG. Its documented API supplies metadata; its licence explicitly covers material preview renders under CC0. API information · Licence.
  • Game-icons.net. Icon previews come from the project's repository through jsDelivr. Named creators and licence links appear with results. Previews requiring attribution are withheld when creator or licence information is missing. The repository specifies CC BY 3.0, with named CC0 exceptions. About and attribution · Licence record.
  • OpenGameArt. Downloadable assets have per-submission licences and attribution instructions. Its FAQ says previews may have different rights, so Magpie directs you to the original page rather than displaying those previews. Existing metadata remains searchable. Robots rules and request limits are enforced, but robots permission alone is not a copyright licence or a grant of access rights. Source FAQ.
  • Kenney. Its asset-page downloads are CC0. Magpie does not treat that as blanket permission for website graphics or logos; previews are withheld pending specific evidence covering them. Asset licence guidance · Website terms.

Keep useful credits

In your credits list, save creator corrections copied from the source, the complete attribution notice, and a description of modifications (or “Unmodified”). You can record when you checked the source and keep an evidence URL. These are your notes, not certification by Magpie. Backups retain them and previous metadata revisions. A generated credits file is a draft to review against the exact applicable terms.

Corrections and removal requests

If an entry identifies the wrong creator or licence, or you are a rights holder requesting removal, submit a correction or removal request. Include the asset/source URL, the requested change and a public reference supporting it. GitHub issues are public: do not include private identity documents, addresses, contracts or credentials.

Requests are reviewed by the project maintainer. Upheld publication exclusions are applied on every site build, so a recrawl cannot silently republish an excluded entry. Requests involving repository history require separate review; excluding an entry from the site does not erase past Git commits.

Storage and external requests

Search runs locally after loading the static index. Project notes are stored in your browser and in backups you choose to download; there is no Magpie account or project-upload server. GitHub Pages serves the site, and permitted external previews contact their image hosts, which receive normal network information such as your IP address. Magpie adds no analytics or advertising. Clearing browser storage can remove your project notes, so keep a backup.
